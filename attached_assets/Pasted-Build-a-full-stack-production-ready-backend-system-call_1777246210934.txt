Build a full-stack production-ready backend system called **Agrillion Core API** that powers multiple applications (Agrillion Mart, Agrillion Smart, Agrillion Tech) using a **single database and single authentication system (SSO)**.

## 🧠 Core Requirements

* One backend API
* One PostgreSQL database
* One login system (JWT-based authentication)
* Unique Membership ID (AGID) for every user
* Multi-app support (Mart, Smart, Tech all use same API)

---

## ⚙️ Tech Stack

* Backend: Node.js with Express (or NestJS if preferred)
* Database: PostgreSQL (use Prisma ORM)
* Auth: JWT (access + refresh tokens)
* Password hashing: bcrypt
* Environment config: dotenv

---

## 🗄️ Database Schema (Prisma)

Create the following models:

### User

* id (UUID)
* agid (unique, auto-generated like AGR-000001)
* fullName
* email (unique)
* phone
* passwordHash
* createdAt

### Session

* id
* userId
* refreshToken
* expiresAt

### Wallet

* id
* userId
* type (POINTS, SHARES, CASH)

### Transaction

* id

* createdAt

### Product (Mart)

* id
* name
* price
* stock
* category

### Order (Mart)

* id
* userId
* totalAmount
* status
* createdAt

### FarmReport (Tech)

* id
* userId
* productId
* quantity
* location
* status
* createdAt

## 🔑 Authentication System

Implement:

* POST /auth/register

  * Create user
  * Auto-generate AGID
  * Hash password
  * Create default wallets (POINTS, SHARES)

* POST /auth/login

  * Validate credentials
  * Return access token + refresh token

* GET /auth/me

  * Return current logged-in user using JWT

* POST /auth/refresh

  * Generate new access token

---

## 💰 Wallet System

Endpoints:

* GET /wallets → return all user wallets
* POST /wallets/convert

  * Convert POINTS → SHARES

Implement logic:

* 100 points = 1 share (configurable)
